# C Programming Practice & Number Programs

A collection of foundational C programs covering basic arithmetic, number operations, loops, conditional statements, and pattern printing.

## 📌 Topics Covered

- **Basic Arithmetic & Formulas:** Distance between two points, circle area, simple calculations.
- **Conditionals:** Leap year check, even/odd, voting eligibility, largest of three numbers, grading system.
- **Loops & Numbers:** Factorial, Fibonacci series, prime number check, sum of digits, decimal to binary conversion.
- **Patterns:** Star patterns, inverted right triangles, alphabet patterns, character pyramids.

## 🚀 How to Compile and Run

To compile and run any of the C programs using GCC:

```bash
# Compile the source file
gcc filename.c -o output

# Run the compiled program
./output
